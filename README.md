## 렌더링 기능

### 텍스처 매핑 & 빌보드

- 정점의 UV 좌표와 텍스처 샘플링을 이용해 이미지의 원하는 영역을 표시합니다.
- 카메라 방향에 맞춰 회전하는 **Screen-Aligned Quad**로 빌보드를 구현했습니다.
- Vertex Buffer와 Index Buffer를 사용해 메시와 텍스처가 적용된 Quad를 렌더링합니다.

### 폰트 아틀라스 & 실시간 텍스트

- 폰트 아틀라스에서 문자별 UV 영역을 참조해 문자열 메시를 생성합니다.
- **영문·숫자·한글**을 지원하며, 문자열 변경에 따라 메시를 갱신합니다.
- 오브젝트 위에 UUID 라벨을 표시하고, 라벨이 대상 오브젝트의 위치를 따라가도록 구성했습니다.
- 텍스트가 카메라를 향하도록 처리해 시점을 바꿔도 읽을 수 있습니다.

### SubUV 애니메이션

- 하나의 스프라이트 시트를 행과 열로 나누고, 시간에 따라 UV 영역을 변경합니다.
- **폭발(Explosion)** 과 **불꽃(Fire)** 효과를 생성할 수 있습니다.
- 재생 설정에서 프레임 범위, 재생 시간, 재생 속도와 반복 여부를 지정할 수 있습니다.
- 반복하지 않는 효과는 재생이 끝나면 삭제하도록 처리했습니다.

### Batch Line & 디버그 시각화

- 여러 선의 정점과 인덱스를 모아 배치 단위로 렌더링합니다.
- 월드 그리드와 좌표축을 표시하며, UI에서 그리드 간격을 조절할 수 있습니다.
- 오브젝트의 월드 **AABB(Axis-Aligned Bounding Box)** 를 계산하고 선택 시 화면에 표시합니다.
- Point Light의 범위와 Spot Light의 원뿔 등 라이트 편집용 보조선을 표시합니다.

### 뷰 모드 & 화면 갱신

- **Unlit / Wireframe** 모드를 전환해 면 또는 와이어프레임으로 메시를 확인합니다.
- Show Flag로 프리미티브와 빌보드 텍스트의 표시 여부를 각각 제어합니다.
- 윈도우 크기가 변경되면 렌더 타깃과 뷰포트를 갱신하고, 새 화면 비율을 카메라 투영에 반영합니다.

## 에디터 기능

### 오브젝트 생성과 편집

- 구·큐브·원·사각형·삼각형과 라이트, SubUV 효과를 원하는 개수만큼 생성할 수 있습니다.
- 마우스 피킹으로 오브젝트를 선택하고, **Inspector**에서 위치·회전·크기·색상을 편집합니다.
- 이동·회전·크기 조절 기즈모를 제공하며, 선택한 오브젝트는 외곽선 또는 Wireframe 강조 색상으로 구분합니다.
- **Scene Manager** 패널에서 오브젝트 목록을 확인하고 선택할 수 있습니다.

### 카메라와 씬 관리

- 원근 투영과 직교 투영을 전환하고, FOV 또는 직교 화면의 너비를 조절합니다.
- 카메라 이동 속도, 마우스 회전 감도, 휠 속도를 UI에서 설정할 수 있습니다.
- 새 씬을 구성하거나, 배치한 오브젝트 정보를 JSON 기반 `.Scene` 파일로 저장하고 불러올 수 있습니다.

### 작업 UI와 디버깅

- Dear ImGui 도킹 UI로 패널을 배치하고, 상단 **Window** 메뉴에서 패널을 표시하거나 숨깁니다.
- **Engine Debug Info**에서 FPS, UObject 할당 수와 메모리 사용량을 확인합니다.
- **Console**에서 로그를 확인하고 필터링·복사·초기화할 수 있으며, 명령어 자동완성과 입력 기록을 제공합니다.
